# 蜜桃女孩手作工作室｜Peach Girl Store

React + Vite 前端、Google Apps Script 後端、Google 試算表資料庫。

## 專案結構
- `frontend/`：React 購物網站
- `backend/`：Apps Script API
- `database/`：資料表規格
- `docs/`：架構與開發文件
- `legacy/index-original.html`：原始單檔網站備份

## 本機開發
```bash
cd frontend
npm install
npm run dev
```

## 建置
```bash
npm run build
```

目前為 React 架構試驗版。原版商品資料已搬入；購物車完整流程、收藏、會員、結帳及 GAS 真實資料串接尚待分階段移植。
